- 대상: `/ai_modules/llm` (STT 이후 텍스트 → LLM 에이전트), gpt-4o-mini, 로컬 백엔드·MySQL

## 수정 후 재측정 (시나리오 104개: 위 100개 + 언어 전환 4개)

최초 100개 실행(81/100) 뒤 실제 문제로 분류한 항목을 고치고 다시 돌렸습니다. **89/104 통과.** (LLM 특성상 실행마다 일부 달라집니다.)

고친 것
- **결제 시 포인트 질문 무한 반복(J01, C03류):** 서버의 결제 단계 상태(`checkout_progress`)를 터치·빠른 응답이 갱신하지 않아 생기던 문제. `POST /ai_modules/llm/checkout-step`로 화면이 단계를 알리게 했고, 포인트 단계 이후 `start_checkout` 재호출은 거부.
- **말만 하고 도구를 호출하지 않는 문제("포장할래", "카드로 할게요"):** `core/intent_fallback.py`가 주문 유형·결제 시작·결제 수단 액션이 빠졌을 때 규칙으로 보완(순서 규칙 유지).
- **영어로 말했는데 한국어로 답(M01~M04, D01):** 서버가 입력 문자와 선언 언어를 대조해 응답 언어를 정하고, 질문 뒤에 응답 언어 알림을 붙임. 프론트는 발화 언어가 다르면 세션 언어를 바꿈.
- **음료·사이드 목록 질문에 "장바구니가 비어 있습니다"(F03, F04):** 메뉴 카테고리 단어를 장바구니 질문으로 오인하던 판별 수정.
- **J04(결제 취소하고 주문 수정 → 장바구니 삭제):** `clear_cart`는 손님이 전체 삭제를 분명히 말했을 때만 실행.
