# 공학페스티벌 발표자료 (5분) 구성안

> 템플릿: `동양미래대학교_에프파이브_발표자료.pptx` (31장, MIRI COMPANY 영업자료 템플릿)
> 근거: `제출본/과제보고서.pdf`(주 근거), 가이드 PPT, `팀프로젝트현황보고_발표PPT.md`, 기획서 발표자료.
> 중간·최종 보고서 발표자료 PDF는 이미지로만 되어 있어 텍스트를 읽지 못했다. 기획서 발표자료는 읽었다.

## 0. 먼저 지킬 것 (가이드 기준)

- 표지에는 **작품명 / 팀명 / 대학명**만 넣는다. 공학페스티벌 로고는 **우측 상단**, **대학 로고는 넣지 않는다.**
- 모든 슬라이드의 `MIRI COMPANY` 텍스트와 로고를 지우고, 그 자리에 `에프파이브 (F5)`를 넣거나 공학페스티벌 로고로 바꾼다.
- 폰트는 이미 에스코어 드림 계열로 바꿔 둠.
- 내용은 과제보고서에서 가져온다. 과제필요성 → 해결방안 → 주요기술 → 기대효과 순서를 따른다.
- 파일명은 `에프파이브_동양미래대학교_발표자료.pptx`.
- 템플릿 안의 사진과 아이콘(악수 사진, 휴대폰 목업, 인증서 등)은 모두 교체하거나 삭제한다.

## 2. 슬라이드별 내용

### 1. 표지 (템플릿 1)
- 위쪽 `MIRI COMPANY` → 공학페스티벌 로고(우측 상단)
- 제목(작은 글씨): `디지털 약자를 위한`
- 제목(파란 큰 글씨): `음성 및 제스처 중심의 배리어프리 키오스크`
- 하단 `작성일/담당자` → `팀명  에프파이브 (F5)`, `대학명  동양미래대학교`
- 제출본 15장 안의 표지와 문구를 맞춘다.

### 2. 목차 (템플릿 2, 항목 5개)
| 01 기획 배경 | 02 해결 방안 | 03 주요 기능·기술 | 04 성능·시연 | 05 기대효과 |
|---|---|---|---|---|
- 하위 항목(점 3개)은 지우거나 한 줄로 줄인다.

### 3. 기획 배경 (템플릿 4: 키워드 4칸 + 카드 3개)
- 상단 회색 줄: `키오스크는 터치 하나뿐이라 누군가에게는 벽입니다`
- 키워드 4칸(수치):
  - `53.6%` 60대 이상이 "조작이 어렵다"고 응답 (한국소비자원, 2022)
  - `2026.1.28` 무인정보단말기 장애인 편의 제공 의무 시행 (보건복지부)
  - `3,960억 원` 국내 키오스크 시장 (2023, 참고용 추정)
  - `4가지 대상` 고령자 · 시각장애인 · 휠체어 이용자 · 외국인
- 카드 3개:
  - 고령자: 작은 화면과 많은 단계
  - 시각장애인: 화면을 볼 수 없음
  - 휠체어·외국인: 손이 닿기 어렵고 언어 장벽
- 말할 내용: "사용자가 기기에 맞추는 방식을 기기가 사용자에게 맞추는 방식으로 바꾸고 싶었습니다."

### 4. 해결 방안 (템플릿 10: 3열 표)
보고서 표1을 그대로 옮긴다. 가운데 열(`구분`)에는 대상을 넣고, 왼쪽에는 어려움, 오른쪽에는 해결을 넣는다.
- 왼쪽 열과 오른쪽 열의 강조색(파란색/회색)을 맞바꿔서 **해결 쪽을 강조**한다.

| 어려움 | 대상 | F5 해결 |
|---|---|---|
| 작은 화면·복잡한 단계 | 고령자 | 대화형 AI와 음성으로 주문 |
| 화면을 볼 수 없음 | 시각장애인 | 흰 지팡이 감지 시 음성 안내 먼저 제안 |
| 화면에 손이 닿기 어려움 | 휠체어 이용자 | 휠체어 감지 시 손동작 조작 제안 |
| 언어 장벽 | 외국인 | 한·영·중·일 UI와 음성 응답 |

- 한 줄 요약(말로): "터치·음성·손동작을 한 흐름에 묶고, 사용자가 언제든 바꿀 수 있게 했습니다."

### 5. 핵심 기능 3가지 (템플릿 6: 카드 3개 + 휴대폰 목업)
- 휴대폰 목업 사진 → **키오스크 주문 화면 캡처**(`작품사진` 폴더)로 교체
- 카드 `SERVICE 01/02/03` → `기능 1/2/3`
  1. **말로 주문**: "치즈버거 세트 하나 주세요" → AI가 뜻을 파악해 장바구니에 담음
  2. **손동작 주문**: 손을 들고 위·아래·좌·우 스와이프로 메뉴 선택
  3. **다가오는 사람 알아보기**: 흰 지팡이면 음성 주문, 휠체어면 손동작 주문을 권함 (영상은 저장하지 않음)
- 아래 한 줄: `+ 한·영·중·일 4개 언어, 직원용 관리 웹 콘솔`

### 6. 작동 원리 (템플릿 28: 3단계 흐름)
- `01 입력`: 말 · 손동작 · 터치
- `02 처리`: AI가 말뜻을 이해하고 손동작을 인식
- `03 결과`: 장바구니·결제 화면에 반영하고 음성으로 안내, 직원 화면에서 주문 확인
- 단계마다 한 줄만 쓰고 점 목록은 지운다.

### 7. 주요 기술 (템플릿 26: 박스 4개)
| 박스 | 한 줄 |
|---|---|
| 대화형 AI 주문 | 말을 글로 바꾸고, GPT가 뜻을 파악해 주문 처리 |
| 없는 메뉴 방지 | 실제 메뉴 데이터를 검색해서만 답함 |
| 손동작 인식 | 직접 모은 데이터로 학습, 스와이프 인식 |
| 접근 감지 | 경량 모델(3.1MB)이라 라즈베리파이에서도 동작 |

- 박스마다 세부 설명은 쓰지 않는다.

### 8. 성능 결과 (템플릿 24: 그래프 1개 + 수치 4칸)
- 수치 4칸:
  - `91.0%` 스와이프 인식 정확도 (검증 데이터)
  - `0.936` 접근 감지 mAP@0.5
  - `3.1MB` 접근 감지 모델 크기
  - `4개 언어` 한·영·중·일 주문
- 그래프: **LLM 시나리오 자동 시험 통과 수** — 81/100(최초) → 89/104 → 99/104 (`인수인계_2026-10-02.md` 5절 기준)
- 슬라이드에는 한계·향후 평가 문구를 넣지 않는다. 질문이 나오면 구두로 답한다.
- 시험 통과 수는 최신 측정인 `99/104`를 쓴다. 제출본 pptx 11장의 `89/104`는 이전 수치다.

### 9. 시연 영상 + 작품 사진 (템플릿 8: 이미지 + 카드 2개)
- 왼쪽 이미지 영역 → **시연 동영상**(`제출본/에프파이브_동양미래대학교_작품동영상.mp4`)을 넣거나, 발표 때 별도로 재생한다. 가이드 규격은 FHD 16:9다.
- 오른쪽 카드 2개:
  - `말로 주문`: AI와 대화로 주문하고 결제까지
  - `손동작으로 주문`: 손을 대지 않고 카드 결제까지
- 작품 사진 2장(`작품사진1.jpg`, `작품사진2.jpg`)은 이 슬라이드 아래에 작게 넣거나, 시연 직전 슬라이드에 둔다.
- 시연 시간이 가장 길다. 영상이 60초를 넘으면 앞부분 설명(5, 6번)을 줄여서 맞춘다.
