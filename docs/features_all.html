7가지 기능 구현 완료
1
말로 주문
자연어 대화만으로 메뉴 선택 → 옵션 · 수량 지정 → 결제까지 전 과정을 완료할 수 있다
2
목소리로 안내
AI가 각 상황에 맞는 안내 멘트를 실시간으로 생성하여 음성으로 읽어준다
3
메뉴 · 알레르기 질의 응답
"이거 땅콩 들어가?" · "매운 거 없는 메뉴 뭐야?" 같은 자연어 질문에 즉시 답변한다
4
손동작으로 화면 조작
터치 없이 스와이프 · 포인팅 · 핀치 제스처만으로 메뉴 탐색과 선택이 가능하다
5
손가락 수로 수량 지정
손가락을 1~5개 펴는 동작으로 주문 수량을 지정한다 (UI 연동 진행 중)
6
취약계층 자동 인식 · 모드 전환
카메라가 흰 지팡이를 감지하면 음성 안내 송출 + 대화 모드를 자동으로 활성화한다
7
다국어 자동 대응
사용자가 영어 · 중국어 · 일본어로 말하면 해당 언어를 인식하고 같은 언어로 응답한다
