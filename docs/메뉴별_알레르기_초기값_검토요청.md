# 메뉴별 알레르기 초기값 검토 요청

## 문서 목적

관리자 페이지의 메뉴 수정 화면에 등록할 알레르기 유발물질 초기 체크값을 정리한 문서입니다.

현재 값은 `backend/core/seed.py`의 메뉴 설명과 주요 재료 문구를 바탕으로 추정한 개발용 초안입니다. 실제 원재료명, 소스 성분, 가공품 성분표, 조리 환경 및 교차접촉 가능성을 확인한 공식 정보가 아닙니다.

> 조장 및 메뉴 담당자는 실제 레시피와 납품 원재료 성분표를 기준으로 반드시 재검토한 뒤 관리자 페이지에서 수정해 주세요. 미체크 상태는 해당 알레르기가 절대 없거나 섭취가 안전하다는 의미가 아닙니다.

## 특히 확인이 필요한 항목

1. 모든 버거 번에 난류, 우유, 대두 또는 기타 표시 대상 성분이 포함되는지
2. 불고기·데리야끼 소스에 밀, 대두 외 다른 표시 대상 성분이 포함되는지
3. 마요네즈·타르타르·화이트 소스에 난류와 우유가 실제로 포함되는지
4. 튀김옷과 시즈닝의 전체 성분
5. 같은 튀김유와 조리 기구 사용에 따른 교차접촉 가능성
6. 비건 버거가 동물성 원료와 교차접촉되는지
7. 음료 완제품, 특히 어린이 음료의 공식 알레르기 표시
8. 아황산류가 소스, 가공육, 음료 등에 기준치 이상 포함되는지

## 시스템 반영 방식

- 관리자가 메뉴 수정 화면에서 알레르기 유발물질을 복수 선택합니다.
- 저장하면 선택값이 `menu_item_allergens` 테이블에 반영됩니다.
- LLM은 메뉴 API와 검색 인덱스를 통해 해당 값을 읽고 음성 안내에 사용합니다.
- 안내 시에는 “안전하다”라고 단정하지 않고, 등록된 유발물질과 교차접촉 가능성을 함께 고지해야 합니다.

## 코드 위치

- 초기 알레르기 19종 및 메뉴별 초깃값: `backend/core/seed.py`
- DB 모델: `backend/core/models.py`
- 관리자 저장 API: `backend/api/admin/menu.py`
- 관리자 체크 화면: `frontend/src/admin/pages/MenuPage.jsx`
- LLM 메뉴 검색 반영: `ai_modules/llm/rag.py`
