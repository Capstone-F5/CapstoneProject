### 슬라이드 1. 표지

안녕하세요. 저희 F5팀은 **디지털 약자를 위한 음성·제스처 중심의 배리어프리 키오스크**를 개발하고 있습니다.
지금부터 현재까지의 프로젝트 진행 상황과 앞으로의 계획을 말씀드리겠습니다.

### 슬라이드 2. 목차

발표는 프로젝트 개요부터 1학기 결과와 방학 중 개발 현황, 기능 및 AI 모델 구현 상황, 시스템 통합 결과를 살펴본 뒤, 2학기 계획과 논문 작성 계획 순서로 진행하겠습니다.

### 슬라이드 3. 프로젝트 개요

기존 키오스크는 대부분 한국어만 지원하고, 터치 중심이라 고령자나 시각장애인, 외국인에게 사용상의 어려움이 있습니다.
저희는 이를 해결하기 위해 **음성 주문, 제스처 제어, 흰 지팡이 감지, 다국어 지원** 기능을 적용했습니다.

### 슬라이드 4. 팀 구성

팀은 총 6명으로 구성되어 있으며, 프론트엔드와 UI·UX, 백엔드와 AI, 데이터베이스 영역으로 역할을 나누어 개발을 진행하고 있습니다.
GitHub를 통해 기능 단위로 이슈와 PR을 관리하며 협업하고 있습니다.

### 슬라이드 5. 프로젝트 최종 목표

최종 목표는 **LLM과 컴퓨터 비전을 활용한 배리어프리 버거 키오스크 웹 앱**을 완성하는 것입니다.
핵심 기능은 음성 주문, 제스처 제어, 시각장애인 지원, 4개 국어 지원, 관리자 시스템까지 총 다섯 가지입니다.

### 슬라이드 6. 1학기 주요 설계 결과

1학기에는 Whisper 기반 음성인식, GPT 연동, 제스처 기능과 기본 UI를 구현했습니다.
이를 통해 React 프론트엔드와 FastAPI 백엔드, AI 모듈이 연결되는 기본 시스템 구조를 완성했습니다.

### 슬라이드 7. 초기 계획 대비 변경사항

개발 과정에서 실제 운영과 성능을 고려해 일부 기술을 변경했습니다.
DB는 SQLite에서 MySQL로 변경했고, STT 모델과 배포 방식도 개선했습니다.
또한 흰 지팡이 감지와 관리자 시스템, 할인·쿠폰 기능 등 초기 계획에 없던 기능도 추가했습니다.

### 슬라이드 8. 현재 시스템 아키텍처

현재 시스템은 React 프론트엔드와 FastAPI 백엔드, MySQL 데이터베이스로 구성되어 있습니다.
백엔드에서는 STT, LLM, 제스처와 흰 지팡이 감지 같은 AI 기능을 처리하고, REST API와 SSE, WebSocket을 통해 프론트와 연동하고 있습니다.

### 슬라이드 9. 방학 중 개발 목표

방학 동안에는 1학기 결과를 실제 사용 가능한 수준으로 발전시키는 것을 목표로 했습니다.
백엔드 완성, 관리자 시스템 구축, 프론트와 백엔드 재연동, 접근성 기능 강화, 외부 배포 환경 구축을 중심으로 개발했습니다.

### 슬라이드 10. 방학 개발 타임라인

6월 말부터 DB와 LLM 연동을 시작했고, 7월에는 관리자 시스템과 Phase 2 통합을 집중적으로 진행했습니다.
8월에는 할인 기능을 개선하고, 마지막으로 흰 지팡이 감지 기능까지 추가했습니다.

### 슬라이드 11. 팀원별 개발 기여

방학 중에는 각 담당 영역을 중심으로 병렬적으로 개발을 진행했습니다.
프론트와 관리자 UI, LLM 및 CV, 백엔드 파이프라인, DB 확장, UI·UX 설계를 각각 담당했으며, 현재까지 머지된 PR은 총 15개입니다.

### 슬라이드 12. 전체 기능 구현 현황

현재 음성 주문, 제스처, 다국어, 할인·쿠폰, 관리자 시스템 등 주요 기능은 대부분 구현된 상태입니다.
일부 관리자 UI와 손가락 번호 연동 등 세부 기능이 남아 있으며, 전체 진행률은 약 **85%**입니다.

### 슬라이드 13. 핵심 기능 ① 음성 대화 주문

음성 주문은 사용자의 음성을 STT로 텍스트로 변환한 뒤, LLM이 주문 내용을 이해하고 필요한 기능을 실행하는 구조입니다.
결과는 화면에 실시간으로 반영되고 TTS로 다시 안내됩니다.
또한 잘못된 결제 진행이나 환각을 막기 위한 코드 수준의 안전장치도 적용했습니다.

### 슬라이드 14. 핵심 기능 ② 비접촉 제스처 인식

제스처 기능은 웹캠에서 손의 21개 관절 위치를 추출한 뒤 MLP 모델로 제스처를 분류합니다.
이를 통해 화면 이동이나 선택, 수량 조절 등을 손동작만으로 수행할 수 있습니다.

### 슬라이드 15. 핵심 기능 ③ 흰 지팡이 접근 감지

시각장애인 접근성 향상을 위해 흰 지팡이를 자동으로 감지하는 기능을 추가했습니다.
웹캠에서 흰 지팡이가 일정 신뢰도 이상으로 감지되면 자동으로 음성 모드로 전환하고 '햄버거 주문을 위한 키오스크 입니다'라는 키오스크 사용 음성 안내를 제공합니다.

### 슬라이드 16. AI 모델 구현 현황

현재 총 7종의 AI 관련 모델과 기술을 시스템에 적용했습니다.
음성인식과 LLM, TTS, RAG뿐 아니라 정적·동적 제스처 모델과 흰 지팡이 감지 모델까지 모두 구현된 상태입니다.

### 슬라이드 17. LLM 에이전트 구성

LLM은 GPT-4o-mini와 LangChain Agent를 사용하고 있습니다.
메뉴 검색, 장바구니 추가와 삭제, 포인트 조회, 화면 이동 등 총 **11개의 Tool**을 연결해 실제 키오스크 기능을 자연어로 제어할 수 있도록 구현했습니다.

### 슬라이드 18. LLM 시나리오 자동화 테스트

LLM이 실제 주문 과정에서 정상적으로 동작하는지 확인하기 위해 7개의 자동화 테스트 시나리오를 만들었습니다.
다국어 응답, 주문 방식 선택, 결제, 장바구니 무결성 등을 검증했으며 현재 7개 시나리오 모두 통과했습니다.

### 슬라이드 19. 데이터 확보 및 전처리

제스처 데이터는 직접 수집했고, 흰 지팡이 모델은 공개 데이터셋을 기반으로 학습했습니다.
제스처의 경우 좌우 반전, 회전, 노이즈 추가 등 데이터 증강을 적용해 다양한 상황에서도 인식할 수 있도록 학습했습니다.

### 슬라이드 20. 시스템 통합 현황

현재 메뉴와 주문 등의 일반 기능은 REST API, LLM 응답은 SSE, 실시간 영상 기능은 WebSocket으로 연결하고 있습니다.
키오스크 기본 흐름부터 관리자 시스템, 흰 지팡이 감지와 할인·쿠폰까지 주요 시스템 통합은 완료된 상태입니다.

### 슬라이드 21. 계획 대비 진행률

현재 전체 프로젝트 진행률은 약 **85%**이며, AI 모델과 시스템 통합은 약 90% 수준입니다.
핵심 기능은 대부분 완성됐기 때문에 앞으로는 세부 기능과 테스트, 안정화 작업에 집중할 예정입니다.
음성 주문과 제스처, 다국어, 관리자 시스템은 계획대로 진행되었습니다.
특히 흰 지팡이 감지와 LLM 자동화 테스트, 외부 데모 환경은 초기 계획보다 추가적으로 구현한 부분입니다.
반면 일부 관리자 UI와 회원 기능, 정량적인 AI 성능 측정은 보완이 필요합니다.

### 슬라이드 22. 잔여 이슈 현황

우선적으로 알레르기 선택 UI, 손가락 번호 연동, 관리자 화면 디자인을 처리하고, 이후 할인 중복 관리와 회원 기능 등을 순차적으로 완성할 계획입니다.

### 슬라이드 23. 2학기 개발 계획

9월에는 우선순위가 높은 UI 기능을 완성하고, 10월에는 회원과 할인 기능 및 API 정합성을 보완할 예정입니다.
11월에는 사용자 테스트와 성능 측정, 시스템 안정화를 진행하고 12월에는 최종 발표와 보고서를 준비할 계획입니다.

### 슬라이드 24. 중간발표 및 최종발표 목표

중간발표까지는 우선순위가 높은 미완 기능을 완료하고, 제스처 인식과 LLM 테스트 수준을 높이는 것이 목표입니다.
최종발표에서는 모든 기능을 안정화하고 실제 사용자 사용성 평가와 AI 모델의 정량적인 성능 결과까지 제시할 계획입니다.

### 슬라이드 25. 논문 주제 및 연구문제

프로젝트 결과를 바탕으로 배리어프리 키오스크 시스템의 설계와 구현에 대한 논문을 작성할 예정입니다.
주요 연구 내용은 LLM 주문 정확도, 제스처 제어의 실용성, 그리고 흰 지팡이 감지 기능이 실제 접근성 개선에 도움이 되는지를 평가하는 것입니다.
평가는 LLM 시나리오 통과율, 제스처 F1-score, STT의 WER, 흰 지팡이 감지 정확도와 SUS 사용성 점수 등을 활용할 예정입니다.
9월부터 관련 연구를 조사하고, 10월과 11월에 실험을 진행한 뒤 12월까지 논문을 완성하는 일정입니다.

### 슬라이드 26. 관리자 시스템 기능 상세

관리자 시스템은 JWT 인증을 기반으로 메뉴, 주문, 회원, 쿠폰, 결제, 통계 등 총 8개 영역으로 구성했습니다.
현재 대부분의 기능은 구현이 완료됐고, 할인 중복 적용과 관련된 일부 기능만 추가 개발 중입니다.
이를 통해 키오스크 사용 기능뿐만 아니라 실제 매장 운영을 위한 관리자 기능까지 함께 구현했습니다.

### 슬라이드 27. 마무리

이처럼 키오스크 사용자 기능과 관리자 기능을 포함해 현재 전체 진행률은 약 85%이고, 핵심 기능은 대부분 구현과 통합이 완료되었습니다.
2학기에는 남아 있는 기능과 사용자 테스트, 성능 평가를 마무리해 완성도를 높이겠습니다.
최종적으로 **터치를 넘어 음성과 제스처로 누구나 쉽게 사용할 수 있는 키오스크**를 완성하는 것이 저희 팀의 목표입니다. 감사합니다.
