## 지연 원인 분석

### 손동작 UI
수량 선택 UX 설계가 예상보다 복잡하고, HW 카메라 위치 확정 후 연동 방식을 결정해야 해서 병목이 발생했다.

### 하드웨어 제작
3D 모델링의 정밀도 요구 수준이 높고, 출력 시간이 상당히 소요되어 일정이 지연됐다.

### 통합 테스트
HW 조립 완료가 선행 조건이라 SW가 준비됐음에도 테스트를 진행할 수 없는 상황이다.

### 공통 원인
방학 중 원격 개발 환경으로 인한 즉각적인 협업·테스트 환경 제약이 전반적인 병목으로 작용했다.
