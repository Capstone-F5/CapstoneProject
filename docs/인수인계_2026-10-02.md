## 2. 이번에 한 작업 (커밋 순서)

### Pi·서버 운영
- **포트 자동화**: `start_servers.ps1`이 Vite를 5173부터 빈 포트로 띄운다(백엔드는 8000부터). Pi는 `deploy/raspberry-pi/start_kiosk.sh`가 **기본으로 운영 서버 `https://cap.dmuce-stu.kr`** 를 열고(서버가 응답할 때까지 기다림), 개발할 때만 Pi의 `~/kiosk-helper/dev_host` 파일에 개발 PC 주소를 적으면 그 PC의 5173~5200 중 이 앱이 응답하는 포트를 찾아 접속한다(파일을 지우면 다시 운영 주소). Chromium 시리얼 자동 허용 정책도 5173~5200으로 확장.
- **지팡이·휠체어 감지 켬**: `frontend/src/App.jsx`의 `APPROACH_DETECTION = true`. 추론은 **서버 PC**(`/ws/approach`, Pi는 프레임만 2fps로 보냄). 서버에 `ai-edge-litert`가 필요(`backend/requirements.txt`에 추가, `numpy<2` 고정). 모델 `ai_modules/cv/models/best_int8.tflite`는 저장소에 있음.
- **`frontend/public/mediapipe-tasks/`(19MB) 커밋**: `useGesture.js`가 불러오는 wasm·모델이 저장소에 없어 새로 받으면 제스처가 404가 되던 문제.
- **채팅(음성인식) 껐다 켜기 수정** (`ChatPanel.jsx`): 인사말은 세션당 1회, 끌 때 재생 대기·TTS 큐를 풀어 마이크가 다시 켜지게 함. **실제 화면에서는 아직 확인 못 함.**
- **TTS 종료 후 마이크 재개 지연 600ms → 250ms**. 에코로 말이 끊기면 400ms 정도로 올릴 것.

### 음성 주문(LLM) 신뢰성
- 가격 질문: `list_menu`를 가격순 정렬 + 버거 최저·최고가 + 세트 추가 요금(+2,000원) 표기, 가격 비교는 `list_menu`를 쓰도록 도구 설명·프롬프트 수정
- 에이전트 반복 한도 초과 시 내부 문구(`Agent stopped…`)가 손님에게 나가던 것을 안내문으로 치환
- 카메라·제스처·언어 설정은 모든 화면에서 가능하다고 프롬프트에 명시(메뉴 화면에서 "카메라 꺼줘"를 거절하던 문제)
- 전화번호 자릿수 검증(숫자 뒤 어미 "이요"를 숫자로 세던 오류 수정), 장바구니 열기, `points` 액션 누락 보완(`backend/core/intent_fallback.py`)
- **STT 교정**: "내장에서 먹을게" → "매장에서 먹을게"(`ai_modules/llm/guards.py`의 `fix_stt`). 교정 전 원문은 대화 로그 `stt_original`에 기록.

### 규칙 기반 가드 (AI를 거치지 않는 코드)
판정에 LLM을 쓰지 않아 **추가 API 비용 0**. 모드는 환경변수 `GUARD_MODE=enforce(기본)|shadow|off`.

| 파일 | 역할 |
|---|---|
| `ai_modules/llm/guards.py` | 거절 예산(한 턴 2번)·모드, 수량·삭제 의도·질문형 규칙, 응답-액션 일치 검사, 노이즈 게이트, `fix_stt` |
| `ai_modules/llm/order_parser.py` | 문장이 "메뉴+수량+단품"뿐인 단순 주문이면 코드가 직접 풀어 담는 파서 |
| `ai_modules/llm/action_tools.py` | `add_item`/`remove_item`/`update_item_options`에 가드 연결 |
| `ai_modules/llm/action_context.py` | 턴별 컨텍스트(직전 안내, 최근 손님 말, 가드 기록, 중복 추가 키) |
| `backend/core/llm_service.py` | 노이즈 게이트, 응답↔액션 일치 검사, 빠진 주문 보완, 응답에 `guards` 포함 |
| `backend/core/conversation_log.py` | 대화 로그(`backend/logs/conversations/*.jsonl`)에 `guards`·`stt_original` 기록 |

가드가 하는 일:
- `add_item`: 직전 메뉴 id 재사용(버거는 발화 → 직전 안내 → 최근 손님 발화 순으로 비교), 세트·사이드·음료 근거, 단품/세트 미확인, 질문형, 수량. **손님이 말한 대상이 하나로 정해지면 거절하지 않고 맞는 값으로 바로잡는다**(`fixed`).
- `menu_item_id`에 이름이 들어오면("치킨너겟") 이름으로 메뉴를 찾아 준다.
- `remove_item`: 삭제 의사 없으면 거절, "하나만 빼줘"는 전체 삭제 대신 수량 감소로 유도
- `update_item_options`: "담아줘"를 수량 교체로 처리하면 기존 수량에 더함, 수량 변경 대상이 말한 메뉴와 다르면 거절, 세트→단품 전환 때 side/drink 무시
- 같은 턴 중복 `add_item` 무시
- 응답이 "담았습니다/삭제했습니다/변경했습니다"인데 맞는 액션이 없으면 안전한 문구로 치환. 단순 주문이면 코드가 빠진 품목을 담음
- 배경 소리로 보이는 입력(도메인 어휘 없는 짧은 한국어 문장)은 LLM을 부르지 않고 "잘 못 들었어요"

**가드가 개입하면 반드시 기록된다**: 응답의 `guards` 필드, 대화 로그, 시나리오 실행 요약(규칙별 횟수 + 막음/고침/기록만 + 개별 사유).

### 테스트 도구
- `backend/tools/voice_scenario_suite.py`: 시나리오 실행기(기존 104 + Z01~Z21)
- `backend/tools/flow_scenarios_gen.py`: **전체 흐름 시나리오 생성기**. 참조 장바구니로 매 턴 기대값을 자동 계산. 도입부 8종 + 메뉴 조작 22종(담기·삭제·되돌리기·수량·세트 옵션 변경·단품↔세트·재료 제외·터치 혼합) + 결제 6종을 섞는다. 같은 시드는 항상 같은 시나리오.

### Pi 운영 주소 자동 접속 (2026-10-06)
- 서버를 배포한 뒤 Pi가 부팅하면 스스로 `https://cap.dmuce-stu.kr`로 접속하도록 설정했다. **Pi를 재부팅해서 확인함**(재부팅 약 45초 뒤 Chromium이 운영 주소로 자동 접속).
- Chromium 정책(`/etc/chromium/policies/managed/kiosk.json`, 저장소 `deploy/raspberry-pi/chromium-policy.json`)에 운영 주소의 마이크·카메라·소리 자동 재생 허용을 추가했다(권한 팝업을 누를 사람이 없어서). 실제 음성·카메라 동작은 Pi에서 직접 켜 보며 확인해야 한다.
- 함정: **옛 `start_kiosk.sh`가 백그라운드에서 포트를 훑고 있으면 Chromium이 안 뜬다**(개발 PC 서버가 꺼져 있을 때). 스크립트를 교체한 뒤에는 옛 프로세스를 정리하거나 재부팅할 것. ssh로 Chromium을 띄울 때는 `WAYLAND_DISPLAY=wayland-0 XDG_RUNTIME_DIR=/run/user/1000 XDG_SESSION_TYPE=wayland DISPLAY=:0`가 필요하다.

## 3. 다른 PC 환경 세팅

1. **저장소**: `git clone` 후 `git checkout perf/mediapipe-webworker`
2. **conda 환경** `kiosk-backend`(Python 3.11): `pip install -r backend/requirements.txt`
   - 설치 후 `numpy`가 2.x로 올라가면 `langchain-community`가 깨진다 → `pip install "numpy<2"` (requirements에 고정해 두었다). `pip check`의 `ml-dtypes requires numpy>=2` 경고는 있어도 임포트·추론은 정상.
3. **MySQL**: 로컬 MySQL(`localhost:3306`)이 필요하다. 이 PC는 conda 환경 `kiosk-mysql`의 `mysqld`를 데이터 폴더 `C:\Users\AILAB\kiosk-mysql-data`로 띄웠다(저장소 밖). 다른 PC에서는 새로 만들면 앱이 시작할 때 시드한다. 가이드: `docs/MySQL_전환_가이드.md`
4. **`.env`**(gitignore): `OPENAI_API_KEY` 등을 새로 만들어야 한다. 키는 별도 전달.
5. **프론트**: `cd frontend && npm install` (postinstall이 VAD 에셋 복사)
6. **실행**: 루트에서 `start_servers.ps1`(백엔드는 8000부터, Vite는 5173부터 빈 포트 자동). 다른 프로젝트가 8000을 쓰고 있으면 8001 등으로 올라간다 — 시나리오 실행 시 `--url`을 실제 백엔드 포트로 줄 것.

## 4. 테스트 실행 방법

### 단위 테스트 (비용 0, 항상 먼저)
```
cd backend
PYTHONPATH=.:<저장소 루트 절대경로> python -X utf8 -m unittest tests.test_guards tests.test_action_guards tests.test_order_parser tests.test_flow_gen tests.test_cart_context
```
(pytest는 설치돼 있지 않다. `ai_modules`와 `core`가 둘 다 임포트되도록 `PYTHONPATH`에 `backend`와 저장소 루트를 모두 넣어야 한다.)

### 시나리오 (LLM 호출 = 비용 발생)
```
cd backend
python -X utf8 tools/voice_scenario_suite.py --url http://localhost:8001 --only Z01 Z21            # 특정 시나리오
python -X utf8 tools/voice_scenario_suite.py --url http://localhost:8001 --category 대량흐름       # 고정 100개 (≈1,100턴)
python -X utf8 tools/voice_scenario_suite.py --url http://localhost:8001 --category 대량흐름 --dry-run   # 발화·기대 장바구니만 (비용 0)
python -X utf8 tools/voice_scenario_suite.py --url http://localhost:8001 --random 10 --seed 7     # 랜덤 10개
python -X utf8 tools/voice_scenario_suite.py ... --json out.json --workers 4                       # 결과 저장·동시 실행 수
```
- **비용 감각**: 말 한 턴 ≈ 0.004~0.008달러(gpt-4o-mini 추정, 정확하지 않음). 고정 100개 1회 ≈ 4~9달러, 기존 104개 1회 ≈ 0.5~1달러. 전체를 반복해 돌리지 말고 **실패한 시나리오만** 골라서 돌릴 것.
- 동시 실행(`--workers`)을 늘리면 OpenAI `ReadTimeout`이 늘어난다(4 이하 권장). 타임아웃은 코드 문제가 아니다.
- 실행 요약 끝에 **가드 개입 표**와 **조작별 실패율 표**가 나온다.

2. **W095**: "이제 결제할게요"에 포인트 안내 문구가 없는 문제(결제 중 메뉴 추가 후 다시 결제를 말한 턴).

4. **스트리밍 한계**: 응답 문장은 이미 음성으로 읽힌 뒤라 말-행동 교정은 화면 텍스트·대화 기록만 바로잡는다. 필요하면 스트리밍을 도구 호출 완료 뒤로 미루는 방안 검토.
5. **외국어 가드**: 지금 가드는 한국어 발화 위주(외국어는 근거가 없어 통과). 영어·일본어 키워드 표 추가.
6. **노이즈 게이트 운영 점검**: 실제 매장 로그(`conversations/*.jsonl`의 `guards`)에서 `noise`가 정당한 발화를 막지 않는지. 처음엔 `GUARD_MODE=shadow`로 기록만 해 보는 것도 방법.

8. **PR #76 병합**: 병합 전 확인 목록은 PR 본문 참고(의존성 재설치, 용량, Pi 설정은 저장소 밖, 포트 동작 변경).

## 7. 알려진 함정 (이 환경에서 겪은 것)

- **heredoc 백슬래시**: Bash 도구에서 heredoc으로 파이썬 코드를 쓰면 `\n`·`\s`가 풀려 깨진다. 파일은 Edit/Write 도구로 쓰거나, 패치 스크립트를 파일로 저장해 실행할 것.
- **uvicorn `--reload`**: 파일 수정 뒤 응답 없음이 반복됨 → `--reload` 없이 띄우고 코드를 고치면 직접 재시작.
- **프로세스 종료**: `taskkill /T`로 부모를 죽이면 같은 부모의 다른 서버(예: Vite 부모가 백엔드까지)가 같이 죽는다. 포트로 PID를 찾아 그 프로세스만 종료. `pkill -f 패턴`은 자기 셸을 죽일 수 있다.
- **8000번 포트**: 다른 프로젝트(`visionguide-dashboard`)가 쓰고 있었다. Vite 프록시가 그쪽을 바라보면 이미지·API가 안 불러와진다. `BACKEND_PORT`를 실제 백엔드 포트로 맞춰서 Vite를 띄울 것.
- **MySQL이 꺼져 있으면** 백엔드가 시작 단계에서 죽는다(`Can't connect to MySQL server`).
- **`ml-dtypes`/`numpy` 경고**: 위 3절 참고.
- **저장소에 올리면 안 되는 미추적 파일**: `White cane.v2i.yolo26.zip`(541MB), `wheelchair.v5i.yolo26.zip`, `docs/*-4k.png|svg`, `docs/제스쳐 주문.mp4`, `_workspace/`. 커밋할 때는 `git add -A` 대신 **경로를 명시**할 것.
- Git이 줄바꿈(LF→CRLF) 경고를 낸다. 동작에는 영향 없음.
- 커밋 메시지 규칙: 끝에 `Co-Authored-By: …` 한 줄(세션 지침).
