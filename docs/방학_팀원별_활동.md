# 방학 팀원별 활동 요약 (2026.06.22 ~ 08.24)

---

## 조예성 (팀장)

**큰 업무 ①** 키오스크 프론트엔드 통합 및 관리자 페이지 구현

**큰 업무 ②** AI 주문 흐름 개선 및 서버 배포

> Phase 2 백엔드 API에 맞춰 키오스크 프론트엔드 전체를 재연동하고, 음성 대화 버그 12건 이상 수정. 관리자 페이지 프론트엔드를 단독 구현하여 실제 백엔드에 완전 연동. Cloudflare Tunnel로 외부 접속 환경을 구축하고, 할인 금액 실시간 표시 및 흰 지팡이 감지 기능을 추가했다.

## 서유민

**큰 업무 ①** DB REST API 서버 설계 및 구현

**큰 업무 ②** 제스처 인식 개선 방향 설계 참여

> FastAPI 기반 DAO·DTO·라우터를 직접 설계·구현하여 메뉴·장바구니·주문·결제·회원 전 도메인의 DB API 서버를 완성. 결제 실패 시 상세 오류 원인 반환 예외 처리도 추가. 8월 회의에서 손이 처음 감지된 위치를 원점으로 삼아 조작 에리어를 가변 설정하는 제스처 개선 아이디어를 제안했다.

## 김성원

**큰 업무 ①** LLM AI Tool 개발 및 음성 주문 로직 구현

**큰 업무 ②** 관리자 백엔드 모듈 개발 및 STT 시나리오 테스트

> LangChain action_tools를 DB와 연동하고 결제·주문 확정 흐름을 코드 수준에서 구현. 메뉴 UUID 조회 Tool 추가 및 동시성 버그 수정. 관리자 백엔드 결제·환불·쿠폰·통계 모듈을 임지연과 공동 구현. 음성 오류 문제 시나리오를 직접 발굴하고 STT·LLM·TTS 개선에 기여했으며, 흰 지팡이 감지 기능 개발에도 참여했다.

## 임지연

**큰 업무 ①** AI Tool 및 관리자 백엔드 비동기 구현

**큰 업무 ②** AI 프롬프트 엔지니어링 및 할인·감지 기능 개발

> api_client를 구현하여 LLM 엔드포인트에 세션 주입 구조를 완성하고, 관리자 백엔드 Module C·D·E·F·H(결제·환불·주문·쿠폰·통계)를 전체 async 패턴으로 구현. 이후 LLM 프롬프트를 최적화하여 음성 주문 정확도를 개선하고, 할인 기능 고도화 및 흰 지팡이 접근 감지 기능 개발에 공동으로 참여했다.

## 진수민

**큰 업무 ①** 관리자 페이지 피그마 프로토타입 제작

**큰 업무 ②** 관리자 인증·메뉴·회원관리 백엔드 직접 구현

> 김명서와 함께 대시보드·주문·결제·메뉴·쿠폰·회원 등 관리자 페이지 6개 화면의 피그마 프로토타입을 완성. 이를 바탕으로 Module A·B·G에 해당하는 관리자 인증·메뉴 관리·회원 관리 백엔드를 직접 구현하여 PR로 병합. 방학 후반 할인·주문 관리 PR(#61) 검토 및 병합도 담당했다.
