## 테스트 환경

- 모델: `gpt-4o-mini` (OPENAI_LLM_MODEL)

## 전체 주문 시나리오 (멀티턴)

대기 화면에서 시작해 결제 완료까지 전체 흐름을 7턴으로 검증.

| 턴 | 화면 | 주문유형 | 입력 | 기대 결과 |
|----|------|---------|------|----------|
| T1 | start | None | 치즈버거 세트 하나 주세요 | 매장/포장 먼저 질문 |
| T2 | orderType | None | 매장에서 먹을게요 | order_type(dine-in) + 세트 옵션 질문 |
| T3 | menu | dine-in | 사이드는 치킨너겟, 음료는 사이다로 | add_item(side=치킨너겟, drink=사이다) |
| T4 | menu | dine-in | 감자튀김도 하나 추가해줘 | add_item(menu_id=13) |
| T5 | menu | dine-in | 치즈버거 세트 2개로 바꿔줘 | update_qty(menu_id=5, quantity=2) |
| T6 | menu | dine-in | 지금 장바구니에 뭐 담겨있어? | 장바구니 내용 복창 |
| T7 | cart | dine-in | 카드로 결제할게요 | start_checkout + points(no) + payment_method(card) |

### 1차 결과 및 발견 사항

| 턴 | 평가 | 발견된 문제 |
|----|------|-----------|
| T1 | ❌ | order_type 자동 선택(dine-in) + start_checkout까지 실행 |
| T2 | ❌ | 매장 선택 후 불필요한 start_checkout 호출 |
| T3 | ❌ | 사이드/음료 답변 후 또 start_checkout 호출 |
| T4 | ❌ | 감자튀김(단품 ID 13)을 update_qty로 잘못 처리 → "장바구니에 없음" |
| T5 | ❌ | update_qty 대신 remove_item + add_item으로 처리 |
| T6 | ✅ | - |
| T7 | ✅ | start_checkout + points(no) + payment_method(card) |

### 2차 결과 (프롬프트 개선 후)

| 턴 | 평가 | 비고 |
|----|------|------|
| T1 | ✅ | "매장에서 드실 건가요, 포장하실 건가요?" |
| T2 | △ | order_type(dine-in) 후 세트 기본값으로 담음 (사이드/음료 미질문) |
| T3 | △ | 장바구니 빈 상태 전달로 치즈버거 재담기 (테스트 설정 문제) |
| T4 | ❌ | 여전히 감자튀김 단품/세트 옵션 혼동 → 카탈로그 구분 설명 + 규칙 추가 |
| T5 | ✅ | update_qty(menu_id=5, quantity=2) |
| T6 | ✅ | 합계 16,400원 정확히 복창 |
| T7 | ✅ | start_checkout + points(no) + payment_method(card) |

## 프롬프트 개선 이력

| 문제 | 수정 내용 |
|------|---------|
| "결제할게" → 수단 자동 선택 | 수단 미명시 시 `start_checkout`만 호출, 금지 예시 명시 |
| "카드로 결제" → 액션 미발행 | `start_checkout → points(no) → payment_method` 3단계 규칙 추가 |
| 발화 명시 옵션 무시 | 최우선 규칙: "발화에 '단품'/'세트'가 있으면 즉시 처리" |
| 동일 액션 중복 발행 | `quantity` 파라미터 사용, `add_item` 반복 호출 금지 명시 |
| 모호한 요청에 긴 목록 응답 | "어떤 버거로 드릴까요?" 한 문장 규칙 |
| 언어 전환 거부 | 언어 강제 SystemMessage → 기본 언어 권장으로 완화 |
| order_type 자동 결정 | [절대 금지 사항]에 명시 |
| 메뉴 담기 후 자동 결제 | 결제 의사 미표현 시 결제 도구 호출 금지 |
| 감자튀김 단품/세트 혼동 | 카탈로그 구분 설명 추가, `add_item` 사용 규칙 명시 |
| navigate 순서 역전 | `navigate('menu')` 먼저, `select_category` 나중 순서 명시 |
| 수량 변경 시 remove+readd | `update_qty` 도구 사용 규칙 명시 |
