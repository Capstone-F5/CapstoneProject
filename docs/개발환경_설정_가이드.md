# 개발환경 설정 가이드

> 이 프로젝트를 처음 로컬에서 실행하기 위한 가이드.  
> 백엔드(FastAPI), 프론트엔드(React+Vite), DB(MySQL) 세 파트를 각각 실행해야 한다.

---

## 사전 준비 (설치 필요 프로그램)

| 프로그램 | 버전 | 확인 명령 |
|---|---|---|
| Python | 3.10 이상 | `python --version` |
| Node.js | 18 이상 | `node --version` |
| MySQL | 8.0 이상 | `mysql --version` |
| Git | 최신 | `git --version` |

> MySQL은 [MySQL Community Server](https://dev.mysql.com/downloads/mysql/) 또는 **MySQL Workbench** 포함 설치 권장.

## Step 1. 저장소 클론 및 브랜치 확인

```bash
git clone https://github.com/Capstone-F5/CapstoneProject.git
cd CapstoneProject
git checkout main
```

## Step 2. MySQL 데이터베이스 생성

서버를 기동하기 전에 먼저 DB를 만들어야 한다.  
(테이블은 서버가 자동 생성하므로 DB만 만들면 된다)

**MySQL CLI:**
```sql
mysql -u root -p

-- 비밀번호 입력 후
CREATE DATABASE kiosk_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
```

**MySQL Workbench 사용 시:**
1. 좌측 `SCHEMAS` 패널 빈 곳 우클릭 → `Create Schema`
2. Name: `kiosk_db`, Charset: `utf8mb4`
3. Apply

## Step 3. 환경변수 파일 설정

### 백엔드 `.env`

프로젝트 루트에 `.env` 파일 생성 (`.env.example` 복사 후 수정):

```bash
cp .env.example .env
```

`.env` 파일 열어서 아래 값 입력:

```env
OPENAI_API_KEY=sk-...          # OpenAI API 키 (팀장에게 요청)

OPENAI_LLM_MODEL=gpt-4o-mini
OPENAI_STT_MODEL=whisper-1
OPENAI_TTS_MODEL=tts-1
OPENAI_TTS_VOICE=alloy

DB_HOST=실제DB서버주소
DB_PORT=3306
DB_USER=계정명
DB_PASSWORD=비밀번호
DB_NAME=kiosk_db

HOST=0.0.0.0
PORT=8000

API_BASE_URL=http://localhost:8000
```

> DB 접속 정보는 팀장(조예성)에게 요청한다.  
> 전체 URL을 직접 지정하고 싶다면 개별 변수 대신 아래 한 줄로 대체 가능:  
> `DATABASE_URL=mysql+aiomysql://계정:비밀번호@호스트:3306/kiosk_db?charset=utf8mb4`

### 프론트엔드 `.env`

`frontend/` 폴더 안에 `.env` 파일 생성:

```bash
# frontend/.env
VITE_API_URL=http://localhost:8000
```

> 이 값이 없으면 프론트엔드가 정적 더미 데이터를 사용한다. 백엔드 연동 테스트 시 반드시 설정할 것.

## Step 4. 백엔드 환경 설정

### 가상환경 생성 및 활성화

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Mac / Linux:**
```bash
python -m venv venv
source venv/bin/activate
```

### 패키지 설치

```bash
pip install -r backend/requirements.txt
```

> `mediapipe` 설치가 오래 걸릴 수 있음. 제스처 기능이 당장 필요 없다면 `requirements.txt`에서 CV 섹션 주석 처리 후 설치해도 됨.

---

## Step 5. 백엔드 서버 실행

```bash
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**정상 기동 확인:**
- 터미널에 `Application startup complete.` 출력
- 브라우저에서 `http://localhost:8000/docs` 접속 → Swagger UI 확인
- `http://localhost:8000/health` → `{"ok": true}` 반환

**첫 기동 시 자동으로 처리되는 것:**
- MySQL `kiosk_db`에 테이블 13개 자동 생성
- 버거·사이드·음료·옵션 시드 데이터 자동 삽입

---

## Step 6. 프론트엔드 환경 설정 및 실행

```bash
cd frontend
npm install
npm run dev
```

**정상 기동 확인:**
- 터미널에 `Local: https://localhost:5173` 출력
- 브라우저에서 `https://localhost:5173` 접속 (HTTP가 아닌 **HTTPS**)

> **HTTPS인 이유:** 카메라(MediaPipe)와 마이크(VAD) 접근은 브라우저 보안 정책상 HTTPS 필요.  
> 자체 서명 인증서이므로 브라우저에서 "안전하지 않음" 경고가 뜨면 `고급 → 계속` 클릭.

---

## 전체 실행 순서 요약

터미널을 **3개** 열어서 각각 실행:

```
터미널 1 (백엔드)
  cd backend
  uvicorn main:app --reload

터미널 2 (프론트엔드)
  cd frontend
  npm run dev

터미널 3 (필요 시 — MySQL 모니터링)
  mysql -u root -p kiosk_db
```

## 자주 발생하는 오류

### `ModuleNotFoundError: No module named 'mediapipe'`

제스처 모듈 의존성 문제. 서버는 예외 처리가 되어 있어 기동은 되지만, `/health` 응답의 `cv_routers_loaded: false`로 표시됨.  
→ `pip install mediapipe==0.10.14` 로 별도 설치하거나, 제스처 기능 없이 진행.

### `Access denied for user 'root'@'localhost'`

`.env`의 MySQL 비밀번호가 틀렸거나 사용자 권한 문제.  
```sql
ALTER USER 'root'@'localhost' IDENTIFIED BY '새비밀번호';
FLUSH PRIVILEGES;
```

### `Unknown database 'kiosk_db'`

Step 2의 DB 생성을 건너뛴 경우. MySQL에서 `CREATE DATABASE kiosk_db ...` 실행 후 재기동.

### 프론트 `ERR_CERT_INVALID` 경고

Vite BasicSSL 플러그인의 자체 서명 인증서. 브라우저에서 `고급 → localhost로 계속 진행` 클릭.

### `npm run dev` 후 카메라가 안 켜짐

HTTPS(`https://`)로 접속했는지 확인. `http://`로 접속 시 카메라 권한 요청이 차단됨.
