## 요 약

셀프서비스 키오스크의 확산은 서비스 효율성을 높였으나, 화면 중심의 복잡한 절차와 제한된 입력 방식은 고령자·장애인 및 디지털 숙련도나 언어 사용에 제약이 있는 이용자의 독립적인 서비스 이용을 어렵게 한다. 본 연구에서는 이러한 디지털 취약 사용자를 지원하기 위해 대규모 언어 모델(LLM; Large Language Model) 기반 음성 대화와 컴퓨터 비전 기반 비접촉 제스처를 터치와 함께 제공하는 배리어프리 키오스크를 설계하고 구현하였다. 여기서 “맞춤형”은 이용자의 연령이나 장애를 자동 분류하는 것이 아니라, 이용자가 입력 방식과 언어 및 접근성 설정을 직접 선택하고 보조기기 감지를 입력 지원의 보조 수단으로 활용하는 것을 의미한다. 제안 시스템은 음성을 텍스트로 변환한 뒤 대화 문맥과 현재 화면 및 장바구니 상태를 함께 해석하며, 메뉴 검색에는 검색 증강 생성(RAG; Retrieval-Augmented Generation)을, 장바구니와 화면의 상태 변경에는 허용된 도구 호출을 사용한다. 컴퓨터 비전 모듈은 흰 지팡이를 감지하면 음성 모드를, 휠체어를 감지하면 제스처 모드를 제안하며, 이용자는 제안된 모드를 변경하거나 해제할 수 있다. 아울러 입력 인식 성능과 과업 수행 및 주관적 사용성을 함께 측정하는 과업 기반 평가 프레임워크를 설계하였다. 제안 시스템의 정량적 효과는 해당 프레임워크에 따른 추가 실험으로 검증할 필요가 있다.

## ABSTRACT

The spread of self-service kiosks has improved service efficiency, but screen-centered procedures and limited input methods hinder independent use by older adults, people with disabilities, and users with limited digital proficiency or language barriers. This study designs and implements a barrier-free kiosk that offers large language model (LLM)-based voice interaction and computer-vision-based touchless gestures alongside touch input. Personalization here does not mean automatically classifying a user’s age or disability: users themselves select the input method, interface language, and accessibility settings, and assistive-device detection acts only as a supplementary trigger. After speech-to-text conversion, the system interprets utterances together with the dialogue history, current screen, and cart state. Retrieval-augmented generation (RAG) grounds menu retrieval, whereas constrained tool calls perform cart and interface state changes. The vision module proposes a voice mode when a white cane is detected and a gesture mode when a wheelchair is detected, and users can change or disable the proposed mode. The study also defines a task-based evaluation framework covering input recognition, task performance, and subjective usability. Quantifying the system’s effectiveness requires further experiments under this framework.

**Key Words:** Barrier-free kiosk, Computer vision, Large language model, Multimodal interaction, Vulnerable users

## I. 서론

디지털 전환과 비대면 서비스의 확산으로 키오스크는 음식점, 교통 및 공공서비스 등 일상적인 서비스 접점에 빠르게 보급되었다. 그러나 작은 글자와 복잡한 절차, 제한 시간 및 터치 중심의 단일 입력 방식은 고령자와 장애인 및 디지털 기기 사용 경험이 적은 이용자의 독립적인 서비스 이용을 어렵게 한다[1, 2, 10]. 본 논문에서 사회적 약자는 이처럼 키오스크 이용 과정에서 접근성 제약을 겪는 이용자를 가리키며, 이하 “디지털 취약 사용자”로 지칭한다.

이러한 장벽을 줄이기 위해 화면의 시각적 단순화[1, 2], 음성 입력과 LLM·RAG 기반 자연어 처리[3-7], 컴퓨터 비전 기반 보조기기 감지와 비접촉 제스처[8, 9, 11]가 각각 제안되어 왔다. 그러나 검토한 선행연구는 대체로 하나의 입력 방식을 중심으로 구현되어, 동일한 서비스 흐름 안에서 입력 채널 간 전환을 다룬 사례가 제한적이었다. 평가 역시 기능 시연이나 인식·분류 정확도에 집중되어[5, 8, 11], 실제 주문 과업의 완수 여부에 대한 검증은 제한적이었다.

본 연구는 이러한 공백에 대응하여 터치·음성·제스처를 하나의 주문 흐름으로 통합한 배리어프리 키오스크를 설계하고 구현한다. 메뉴 검색에는 RAG를 사용하여 응답을 서비스 데이터에 근거화한다. 다만 검색이 빗나가면 근거가 불충분한 문장이 생성될 수 있으므로[7], 생성된 문장을 그대로 실행에 옮기지 않는다. 장바구니와 화면의 상태 변경은 정해진 도구 호출로만 수행하고, 도구가 실제 메뉴 식별자와 재고를 확인한 뒤 반영하므로 생성 오류가 주문 상태까지 이어지지 않는다. 컴퓨터 비전 모듈은 흰 지팡이를 감지하면 음성 모드를, 휠체어를 감지하면 제스처 모드를 제안하고, 이용자는 제안된 모드를 변경하거나 해제할 수 있다. 따라서 본 연구의 “맞춤형”은 연령이나 장애를 자동으로 분류하는 것이 아니라, 보조기기 감지에 따른 입력 지원과 이용자의 명시적 선택을 결합한 방식을 의미한다. 시스템은 React와 FastAPI로 구현하였으며, 입력 인식과 과업 수행 및 주관적 사용성의 세 계층으로 구성된 평가 프레임워크를 함께 제시한다.

## II. 관련 동향 및 연구

### A. 키오스크 접근성과 음성 상호작용

장애 당사자 초점집단 면담과 국내외 지침 분석을 수행한 연구는 키오스크 접근성 요건을 하드웨어의 크기와 공간, 입력 방식의 보완·대체, 시각의 보완·대체 및 인지의 보완·대체로 분류하였다[10]. 고령자를 대상으로 일반 키오스크와 배리어프리 키오스크를 비교한 연구에서도 정보 탐색은 개선되었으나 전체 사용성에는 유의한 차이가 나타나지 않아, 시각적 단순화만으로는 충분하지 않음을 보였다[2]. 음성 기반 키오스크는 터치가 어려운 이용자에게 대안 채널을 제공하지만[3], 소음과 다양한 표현을 처리하려면 인식 결과 보정과 문맥 기반 의도 분석이 필요하다[4]. 이는 음성을 단독 해결책이 아니라 화면 피드백 및 오류 복구와 함께 제공되는 보완적 입력 채널로 다루어야 함을 시사한다.

### B. LLM 및 RAG 기반 대화형 서비스

LLM을 키오스크에 적용하면 고정된 명령 형식보다 다양한 발화를 처리하고, 누락된 정보를 순차적으로 질문할 수 있다[5]. RAG는 외부 저장소에서 관련 정보를 검색하여 생성 문맥으로 제공하므로 모델을 재학습하지 않고 서비스 정보를 갱신할 수 있다[6]. 그러나 검색 품질이 낮거나 필요한 정보가 없으면 근거가 불충분한 응답이 생성될 수 있다[7]. 이러한 한계를 완전히 배제할 수는 없으므로, 장바구니 변경이나 결제처럼 시스템 상태를 바꾸는 동작은 생성 결과에 맡기지 않고 데이터베이스를 검증하는 도구 호출을 거쳐 실행할 필요가 있다.

### C. 컴퓨터 비전 기반 입력 지원

컴퓨터 비전을 기반으로 한 연구는 두 방향으로 진행되어 왔다. 하나는 휠체어나 지팡이 같은 보조기기를 감지하여 상황에 맞는 화면과 입력 방식을 제공하는 것이고[8], 다른 하나는 MediaPipe Hands의 실시간 손 랜드마크 추정[9]을 이용하여 비접촉 조작을 하도록 하는 것 이다[11]. 다만 자동 감지는 오분류를 동반하고[8], 제스처 인식은 배경과 조명의 영향을 받는다[11]. 따라서 감지 결과를 그대로 적용하기보다, 이용자가 입력 방식을 직접 변경할 수 있는 복구 경로가 함께 필요하다.

### D. 선행연구 종합과 연구 공백

표 1과 같이 기존 연구는 음성, 제스처 또는 적응형 화면 가운데 하나를 중심으로 구현되었으며, 응답을 서비스 데이터에 근거화하는 범위와 적응 방식도 서로 다르다. 평가는 기능 시연이나 인식·분류 정확도에 머물러, 여러 입력 방식이 함께 제공될 때 이용자가 어떤 경로를 선택하고 과업을 완수하는지는 확인되지 않았다. 본 연구는 입력 방식의 통합, 응답 근거화와 상태 변경 실행의 분리, 과업 수준의 평가라는 세 측면을 하나의 시스템에서 다루며, 구체적인 설계는 III장에서 기술한다.

| 5 | 입력 및 응답 지연 | 제스처 발생부터 화면 반응까지, 발화 종료부터 음성-텍스트 변환(STT; Speech-to-Text) 완료·LLM 첫 응답·전체 응답까지 구간별 측정 | 평균, 중앙값, 표준편차 또는 95백분위 지연시간 |
| 6 | 과업 기반 사용성 | 터치 전용 조건과 제안 멀티모달 조건에서 동일 주문 과업 비교 | 참가자 수 N, 성공률, 완료 시간, 재시도·도움 요청 수 |

### 결과 확보 후 교체할 문장

- 국문 요약 마지막 문장의 “추가 실험으로 검증할 필요가 있다”를 실제 핵심 결과 1–2개로 교체한다.
- ABSTRACT 마지막 문장도 국문 결과와 동일한 범위와 수치로 교체한다.
- 실제 평가 방법과 결과는 후속 “실험 및 평가” 장에서 기술한다.
- 실험 전에는 “향상하였다”, “우수한 성능을 보였다”, “접근성을 개선하였다”와 같은 효과 단정 표현을 사용하지 않는다.
