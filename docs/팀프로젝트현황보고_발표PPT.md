<!-- SLIDE 13 - 핵심 기능 1 음성 주문 -->
## 4-2. 핵심 기능 ① 음성 대화 주문

### 동작 흐름

```
마이크 입력
  ↓ VAD (음성 구간 자동 감지)
POST /ai_modules/stt
  ↓ Whisper → 텍스트 + 언어 자동 감지
POST /ai_modules/llm/stream (SSE)
  ↓ LangChain AgentExecutor
  ↓ 11개 툴 실행 (add_item, navigate 등)
  ↓ FAISS RAG 메뉴 검색
SSE 토큰 스트리밍 + 화면 액션 이벤트
  ↓
TTS 음성 재생
```

### 구현 특이사항
- 환각 방지: 결제 우회로 **코드 레벨 가드** 적용
- LLM 메모리: 세션별 SummaryBufferMemory (800 토큰)
- 대화 로그: **JSONL 자동 기록** (`backend/logs/`)

## 4-2. 핵심 기능 ② 비접촉 제스처 인식

### 동작 흐름


- 파일: `static_mlp.pkl`, `dynamic_mlp.pkl`

## 4-2. 핵심 기능 ③ 흰 지팡이 접근 감지

### 동작 흐름

```
웹캠 영상
  ↓ WebSocket /ws/approach (JPEG 바이너리)
YOLOv8 INT8 TFLite 추론 (best_int8.tflite)
  ↓ 신뢰도 ≥ 0.5 감지 시
상태 전환: IDLE → VOICE_MODE
  ↓ 10초마다 최대 3회
"햄버거 주문을 위한 키오스크 입니다" 음성 재생
  ↓ 사용자 터치 시 → IDLE 복귀
```

### 구현 특이사항
- `asyncio.Lock`: 동시 추론 직렬화
- `asyncio.to_thread`: 동기 추론 논블로킹 처리
- TTS: 첫 1회 생성 후 **메모리 캐시** 재사용

## 6-2. 실행 화면 구성

### 12개 화면 플로우

```
시작 화면
  → 주문 방식 선택 (터치 / 음성 / 제스처)
  → 메뉴 화면 (카테고리 탭, 할인 가격 실시간 표시)
  → 아이템 상세 / 단품·세트 선택
  → 장바구니 (쿠폰 스캔, 수량 조절)
  → 결제 선택 (카드 / 현금 / Pay)
  → 주문 완료
```

### 음성 주문 예시 흐름
```
"더블치즈버거 하나 세트로 주세요"
  → STT 전사 → LangChain Agent
  → search_menu(더블치즈버거) → add_item
  → "더블치즈버거 세트를 담았습니다. 사이드와 음료를 선택해주세요"
  → TTS 재생 + 화면 이동
```
